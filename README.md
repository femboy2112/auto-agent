# auto-agent

A repository containing the `agy_orchestrator` project, an advanced multi-agent wrapper.

## Workflows
- **Adversarial**: Generator and Critic agents refine the output iteratively.
- **Tree-of-Thought (ToT)**: Explores multiple branches concurrently and selects the best one.
- **Master**: Combines Tree-of-Thought exploration with Adversarial refinement for robust agentic workflows.
